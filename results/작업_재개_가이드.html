1 VS Code 열고 최신 코드 받기

새 PC이거나, 다른 곳에서 작업이 있었을 수도 있으니 항상 먼저 최신 상태로 맞춥니다.

cd "c:\Antigravity\TEst\Clearing"
git status
git pull origin main

현재 PC에서 계속 작업한다면 이미 최신 상태이므로 git pull은 변경 없음으로 끝납니다.

2 의존성 설치 (필요한 경우만)

node_modules가 없거나 package.json이 바뀐 경우에만 실행하세요.

# 프론트엔드
cd "c:\Antigravity\TEst\Clearing"
npm install

# 백엔드
cd "c:\Antigravity\TEst\Clearing\server"
npm install

3 개발 서버 실행

가장 쉬운 방법은 루트의 run.bat을 더블클릭하는 것입니다. 백엔드(5000)와 프론트엔드(3000) 창이 각각 열립니다.

:: 탐색기에서 더블클릭하거나, 터미널에서:
c:\Antigravity\TEst\Clearing\run.bat

개별 실행: run-backend.bat (server/index.js, DB: construction.db) / run-frontend.bat (vite dev, port 3000)

🖥 PC에서 접속

http://localhost:3000

📱 같은 와이파이의 모바일에서 접속

run.bat 실행 시 콘솔에 표시되는 사설 IP:3000 주소 사용

4 지금 적용된 디자인 컨셉 기억하기

새 작업을 추가할 때 아래 톤을 유지하면 통일감이 유지됩니다.

  • Primary (네이비) #0d1b3e — 사이드바, 헤더 강조, 마감 배지
  • Secondary (그린) #1b6b35 / 포인트 #2ea043 — 활성 메뉴, 강조 버튼, 진행률 바
  • 본문 배경은 옅은 회백색 #f4f6f8, 카드형 흰색 패널 위주
  • 새 화면을 만들 때 tailwind.config.js의 primary / secondary 토큰 클래스를 그대로 사용하면 자동으로 테마가 적용됩니다

자세한 내용은 results/대시보드_리디자인_계획.html 문서를 참고하세요.

5 작업 후 GitHub에 저장하기

작업이 끝나거나 중간 저장이 필요할 때마다 반복하세요.

cd "c:\Antigravity\TEst\Clearing"
git add -A
git commit -m "작업 내용 요약"
git push origin main

DB 백업 파일(server/construction_backup_*.db 등)은 .gitignore에 등록되어 있어 자동으로 제외됩니다. 정식 백업은 backup_version.ps1을 통해 backups/ 폴더에 별도로 보관하세요.
