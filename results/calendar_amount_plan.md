# 캘린더 금액보기 기능 계획

## 목표
- 캘린더 화면에서 하루별 금액 데이터를 확인할 수 있는 버튼을 추가한다.
- 상단 헤더에 현재 선택된 월의 합계 금액을 표시한다.
- 실제 기능 구현은 아직 수행하지 않고, 설계와 화면 미리보기만 문서화한다.

## 대상 화면
- `Clearing/src/components/CalendarView.jsx` 기반 캘린더 화면

## 요구 사항
1. **일일 금액 보기 버튼 추가**
   - 캘린더 상단 탐색 바 우측 또는 왼쪽에 토글 버튼을 배치.
   - 버튼 클릭 시 하루별 금액이 캘린더 셀 내부에 표시되는 모드로 전환.
   - 버튼 상태는 `ON / OFF` 형태로 표시.

2. **월별 총액 표시**
   - 캘린더 상단 헤더 바로 아래 또는 탐색 바 안에 현재 표시 중인 월의 총 금액을 노출.
   - 예: `2026년 06월 총 금액: ₩12,345,000`
   - 월 변경(이전/다음) 시 자동으로 값 갱신.

3. **일별 금액 표시 방식**
   - 캘린더 각 날짜 셀에 `₩xxx,xxx` 형식으로 금액 노출.
   - 금액은 하루의 `summary` 데이터 합계를 기준으로 표시.
   - 금액이 없는 날짜는 표시하지 않거나 `-`로 표시.

4. **데이터 출처 및 계산**
   - `summary` prop에 포함된 `oiling`, `cleaning`, `unloading` 항목을 사용.
   - 각 기록에 `amount` 또는 `price` 필드가 존재한다고 가정.
   - 일일 총액은 해당 날짜의 모든 기록 금액 합산.
   - 월별 총액은 해당 월 전체 일일 금액 합산.

5. **화면 구성**
   - 캘린더 헤더: 월 이동 버튼, 현재 월 텍스트, `오늘` 버튼, `일일 금액 보기` 토글 버튼.
   - 월 총액 표시 영역: 월 제목 바로 아래 위치.
   - 캘린더 셀: 날짜, 작업 아이콘/개수, 토글 시 `일일 금액` 추가.
   - 상세 패널: 선택된 날짜의 세부 작업 목록 아래에 `총 금액` 항목 추가.

## 구현 흐름
1. 캘린더 컴포넌트에 `showDailyAmount` 상태 추가.
2. 상단 탐색 바에 버튼을 추가하여 상태 토글.
3. 일일 데이터 추출 함수에 금액 계산 로직을 추가.
4. 셀 렌더링 시 `showDailyAmount` 활성화 여부에 따라 금액 텍스트 출력.
5. 월 총액을 계산하는 helper 함수를 추가하고 상단에 표시.

## UI/UX 시나리오
1. 사용자가 캘린더를 열면 기본 모드로 작업 일정이 보인다.
2. 상단의 `일일 금액 보기` 버튼을 누르면
   - 날짜 셀 하단에 금액이 표시된다.
   - 월 총액 텍스트가 헤더에 나타난다.
3. 월 이동 시 금액이 다시 계산되어 갱신된다.
4. 날짜를 클릭하면 선택된 날짜의 금액 합계가 상세 패널에 같이 노출된다.

## 미리보기 결과
- `Clearing/results/calendar_amount_preview.html` 파일에 예상 UI 미리보기를 생성한다.
- 미리보기에는 상단 헤더, 월 총액 텍스트, 일별 금액이 포함된 캘린더 카드가 포함된다.

## 검증 기준
- UI 계획 문서가 명확하게 작성되었는가.
- 미리보기 파일에 요청된 버튼/월 총액/일일 금액 표시 모양이 포함되었는가.
- 실제 코드 변경 없이 설계 단계에서 검토가 가능해야 한다.
