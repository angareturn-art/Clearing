⑥ 월별 막대 그래프 상세 설계

구성 요소

  • 왼쪽 패널 — 남은 기성금액(남은 금액 = 총 기성 − 지금까지 마감 합계) 크게 표시, 소수점 없이 만원 단위로
  • 막대 단위 — 마감 처리된 월(monthly_closings)마다 막대 1개
  • 색상 구분 — 기름치칠 navy · 1차청소 green-dark · 2차청소 green-2
  • 진행 중인 월 — 점선 윤곽 막대로 구분
  • 목표선 — 총 기성금액 위치에 점선 수평선 + "목표 1.17억" 레이블
  • 마감 확정 여부 — monthly_closings에 있는 월만 실선 막대 표시

구현 방식 (라이브러리 없음)

  • 외부 차트 라이브러리 미사용 → Tailwind + CSS flex로 직접 구현
  • 각 막대의 높이 = (월 금액 / 총 기성금액) × 최대 높이px
  • 각 세그먼트 높이 = 해당 구분 금액 비례
  • SVG 대신 순수 div 스택 → 반응형 간단, 인쇄 ok
