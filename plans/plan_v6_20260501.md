## 3. 비고 표현 규칙

### 갱폼 박리제 동별 비고
```
형식: {층}(세대수)
예시: 8층(4세대), 9층(4세대)
→ 동별 청구 가능한 모든 작업 층을 쉼표로 나열
→ 기준층 이하 제외
```

### 세대청소 동별 비고
```
형식: {층}({차수})
예시: 2층(2차), 3층(2차), 4층(1차)
→ 완전완료 층만 표시 (미완성 제외)
→ 지하층(B1, B2)은 비고에서 제외 → 기타 작업 섹션으로 이동
```

### 기타 작업 (지하층 청소)
```
- 세대청소 기준층(cleaning_base_floor) 이하이거나 음수층(B1=-1, B2=-2)인 청소 기록
- 비용 계산 대상이 아님 (금액 0원)
- 화면에는 "기타 작업" 섹션으로 별도 표시
- 향후 추가 비용 청구 참고용으로 활용
```
