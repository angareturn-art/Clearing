## 1. 분석 결과 반영 (템플릿 매칭)
제공된 템플릿 파일을 분석한 결과, 다음의 레이아웃 규칙을 적용해야 합니다.

### 1.1 컬럼 배치 (Column Mapping)
- **A열**: 기간 정보, 섹션 제목 (1., 2., 3.) 위치
- **B열**: 테이블 시작 ("동", "작업 내용", "합계 금액")
- **C열**: "세대" 정보
- **D열**: "작업층/세대수", "비고"
- **E열**: "금액" 정보

### 1.2 행 배치 (Row Mapping)
- **1행**: [B1] 현장명 타이틀
- **2행**: [A2] 기간 정보
- **4행**: [A4] 1. 갱폼... (섹션 제목)
- **5행**: [B5:E5] 테이블 헤더
- **데이터**: [B6]부터 시작

---

## 2. 세부 수정 계획

### Backend: `server/index.js` 수정
- `aoa` 배열 구성 로직을 템플릿의 0번 인덱스(`null` 처리)를 고려하여 전면 수정.
- 소계(Subtotal) 행에서 "세대" 합계 위치를 C열로 조정.
- 최하단 "합계 금액"의 위치를 B열로, 금액을 E열로 조정.

### 예시 AOA 구조 (코드 적용값)
```javascript
const aoa = [
  [null, `[${siteName}] 월별 정산 내역서`], // 1행 (B1)
  [`${year}년 ${monthNum}월 (도급기간: ${periodText})`], // 2행 (A2)
  [], // 3행
  ["1. 갱폼 박리제 도급 내역"], // 4행 (A4)
  [null, "동", "세대", "작업층/세대수", "금액"], // 5행 (B5~E5)
  [null, "1동", "8세대", "8층(4세대)...", 592000], // 데이터 (B6~)
  ...
  [null, "소계", totalUnits + "세대", "", totalAmount], // 소계
  ...
  [null, "합계 금액", null, "", totalIncome] // 최종 합계
];
```
