# 통합 매트릭스 화면 디자인 개편 계획

사용자님의 지침에 따라 다른 파일은 절대 수정하지 않고, 오직 `MatrixStatusView.jsx` 컴포넌트의 화면 구성만 변경하여 요구사항을 충족하는 계획입니다.

## User Review Required
> [!IMPORTANT]
> 아래의 UI 디자인 수정 계획을 검토해 주세요. **계획 단계이므로 아직 코드를 수정하지 않았습니다.** 계획이 마음에 드시면 승인(Yes)해 주시면 즉시 구현에 착수하겠습니다.

## 1. 수정 대상
- **대상 파일**: `src/components/MatrixStatusView.jsx` (단일 파일)

## 2. 주요 변경 사항

### 2.1 상단 토글(구분) 버튼 완전 삭제
- 기존에 갱폼박리제칠, 1차청소, 2차청소를 선택하던 탭(버튼) UI와 관련 상태 변수(`viewMode`)를 모두 삭제합니다.

### 2.2 3개의 매트릭스 화면 동시 출력 (3분할 그리드)
- 화면을 3개의 그리드(Grid)로 분할하여 **[ 박리제칠 표 ] | [ 1차청소 표 ] | [ 2차청소 표 ]** 가 가로로 나란히(또는 화면 크기에 맞춰) 한 화면에 동시에 띄워지도록 레이아웃을 변경합니다.
- 각 표의 상단에는 어떤 공정인지 알 수 있도록 작은 제목을 배치합니다.

### 2.3 초고밀도 디자인 적용 (수직 스크롤 제거)
25층 건물의 전체 데이터가 스크롤 없이 한 화면에 들어오도록 표의 여백(Padding)과 폰트 크기를 극단적으로 줄입니다.
- **셀 높이 축소**: 기존 `h-10` (약 40px)에서 `h-5` ~ `h-6` (약 20~24px) 수준으로 절반 이상 대폭 줄입니다.
- **폰트 크기 축소**: 기존 텍스트를 아주 작은 사이즈(`text-[9px]` 또는 `text-[10px]`)로 줄이고 여백(`p-0.5`)을 최소화합니다.
- **넓이 축소**: 가로로 3개의 표가 들어가야 하므로 셀의 가로 너비도 밀도 있게 줄입니다. 

## 3. 예상 화면 구조
```text
[ 박리제칠 현황 ]             [ 1차 세대청소 ]             [ 2차 세대청소 ]
층 | 1동 2동 3동 ... 9동     층 | 1동 2동 3동 ... 9동    층 | 1동 2동 3동 ... 9동
25 | 0/2 0/4 ...            25 | 0/2 0/4 ...            25 | 0/2 0/4 ...
24 | 2/2 4/4 ...            24 | 2/2 1/4 ...            24 | 0/2 0/4 ...
... (위아래 간격 최소화로 25층부터 1층까지 한 번에 표시) ...
 1 | 2/2 0/0 3/3 ...         1 | 2/2 0/0 3/3 ...         1 | 2/2 0/0 3/3 ...
```
